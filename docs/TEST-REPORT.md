## 范围与限制

这不是跨浏览器认证或性能基准。本次未实测 Safari、Firefox、实体手机、React/Vue 编译、跨域服务器组合或长时间压力测试。React/Vue 代码为文档中的接入示例。跨域与后台暂停的相关代码已实现，但本次浏览器回归没有专门模拟第三方服务器 CORS 策略或操作系统后台切换。

缩采样属于算法变更，因此新旧粒子分布和透明度不保证完全一致。没有测量并宣称“快几倍”或固定帧率。1.1.0 检查了官网公开脚本，具体见 OFFICIAL-ANALYSIS.md；本模块独立实现，并没有逐帧验证和复刻官网输出。60/120/165Hz 的一致性测试是数学回归模型的离散时间测试，不是实体显示器性能测试。
