# 官网粒子分析与本模块的对应实现

2026-10-22 检查了官网页面引用的公开构建产物：

- [官网页面](https://ak.hypergryph.com/#world)
- [粒子逻辑和点阵数据所在的公开脚本](https://web.hycdn.cn/arknights/official/_next/static/chunks/app/page-a96c46ff52d96bd7.js)

这些带哈希的地址可能随官网更新而失效。分析基于静态脚本，不代表在所有运行场景下逐帧测量过官网，也无法还原官网内部的离线素材制作过程。

## 已确认的实现

- 世界观组件通过 `parseModel` 读取预置的 `count`、`size`、`points`，每点为 x、y 和可选的 0～255 透明度。世界观六个模型坐标尺寸都是 800×800，坐标位于步长 3 的格网，点数为 3550、4230、3882、4788、3200、5652。模型单位还会经过场景缩放和相机投影，不能等同于 CSS 像素。
- `APS` 使用 Three.js 的 Points、BufferGeometry 和 ShaderMaterial，位置与颜色使用 Float32Array，并通过一张粒子纹理绘制点。构造器粒子池默认容量为 10000；池容量不等于当前图案可见点数。
- 默认模式为 SPREAD。位移包含回归目标的项与鼠标扰动项；扰动向量为远离鼠标的方向向量乘以 `100 / (1 + distance)²`。力的大小在远处近似按距离倒数衰减，没有硬半径。恰好重合时方向向量为零。
- 每粒子的 speed 默认范围为 20～30，回归系数为 `1 / speed`，意味着不同粒子回归速度有差异。官网此段按帧更新，并非毫秒参数。
- 选择模型时会 shuffle 目标，颜色和透明度也逐帧趋近目标。
- 在所读默认运动逻辑中未找到逐粒子持续随机游走或正弦漂浮，不能仅凭静态截图宣称有这类效果。

## 当前模块的取舍（1.3.0）

本模块保留 Canvas 2D 和运行时图片采样，便于直接使用任意图片。采用细格网、小柔边圆点、可调静态错位、无硬半径的鼠标作用、每粒子不同回归时间来接近观察到的特征。

回归改为毫秒时间常数，通过指数积分减少对显示刷新率的依赖。鼠标力度系数经过独立标定；位置在 Canvas 的 CSS 像素空间计算。因此它不是官网 SPREAD 代码的逐帧复制，也不保证原版项目和官网的同参数输出一致。

1.2.0 将切图也改为从当前位置按剩余距离指数回归，而不再默认使用 1.1.0 的固定时长轨迹。每粒子依据自己的时间常数自然收拢，没有共同到达时刻，也不强制加入散开弧线。

1.3.0 根据本模块的响应式问题，独立加入以图片显示矩形长边为基准的鼠标作用缩放；这不是已证明与官网相同的缩放方法。目标是同一图片在不同显示尺寸、相同相对指针位置下保持相近的形变比例，并保留固定 CSS 像素模式供选择。

持续漂浮独立设置为 drift，默认关闭；jitter 只影响静态目标的错位。圆点纹理由模块自行绘制，不使用官网素材。此分析文档不包含官网点阵原数据。
